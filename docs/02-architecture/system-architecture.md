# 系统架构

```text
免登录运营台 ── 草稿/发布 ──> FastAPI + SQLite ── 发布 JSON ──> React Native 客户端
       └── AI 指令 ──> /ai/transform ──> 模型服务（API Key 仅在后端）
```

1. 运营台可编辑草稿；AI 请求带页面 key 与自然语言指令。
2. 后端让模型产出白名单操作，验证节点/属性/Schema，返回候选和差异；不保存。
3. 运营确认后应用候选，再显式发布；发布时快照递增版本。
4. RN 进入页面或手动刷新读取发布配置并缓存。

浏览器、客户端和模型输出都视为不可信。远程配置只有结构、样式 Token 和动作 ID，不包含代码、HTML、表达式或任意 CSS。AI/发布失败不得改动已发布页面。
