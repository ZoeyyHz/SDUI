# AI Copilot 流程

AI 是必须演示场景，使用真实兼容模型 API。

1. 运营提交 pageKey 与指令。
2. 后端把草稿/指令交模型，只允许 move_node、set_prop、set_token 操作。
3. 后端验证节点存在、字段可编辑、类型/值正确，再校验 Schema。
4. 返回候选文档和可读变更，不写数据库。
5. 运营预览并选择应用到草稿；然后单独点击发布。

支持移动模块、修改标题文案、修改预设主题色。无法识别时不改配置。MODEL_API_URL、MODEL_NAME、MODEL_API_KEY 仅放后端环境变量；无真实密钥时 AI 场景不能验收，不用固定回复伪装。
